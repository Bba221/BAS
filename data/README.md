# โฟลเดอร์เก็บข้อมูลนักเรียน/นักศึกษา

โฟลเดอร์นี้ใช้เก็บไฟล์ข้อมูลการสมัครสมาชิกของนักเรียน/นักศึกษาทุกคน

## ไฟล์ในโฟลเดอร์

- `students.json` — ฐานข้อมูลรวม (เก็บทุกคนในไฟล์เดียว อ่านง่าย สำรองง่าย)
- `students/` — แยกไฟล์รายคน 1 ไฟล์ต่อ 1 นักเรียน เช่น `students/6612345678.json`

## โครงสร้างข้อมูลต่อคน

```json
{
  "studentId": "6612345678",
  "name": "สมชาย ใจดี",
  "classroom": "ม.5/2",
  "age": 16,
  "passwordHash": "...",
  "createdAt": "2026-09-21T15:04:05.000Z"
}
```

## หมายเหตุ

- รหัสผ่านถูกเข้ารหัสแบบ hash (SHA-256 + salt) ก่อนบันทึกเสมอ — ไม่เก็บรหัสผ่านตรงๆ
- เว็บแอปบันทึกลง `localStorage` เพื่อให้หน้าเว็บใช้งานได้จริงทันที (ไฟล์ในโฟลเดอร์นี้เป็นตัวอย่างโครงสร้าง/สำรองข้อมูล)
